# Habit Tracker

Habit Tracker is a lightweight Python application for monitoring everyday habits.

It stores a collection of habits, calculates completion rates and generates a simple progress report. The project focuses on clean organization rather than complex functionality.

## Features

- Daily habit list
- Completion tracking
- Progress percentage
- Summary statistics
- Export report

## Example

```
Habits

✔ Morning Exercise
✔ Read 20 Pages
✖ Drink 2L Water
✔ Meditation
✖ Walk 8000 Steps

Completion Rate

60%
```

Run

```bash
python main.py
```
